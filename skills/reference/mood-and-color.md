# 心情与颜色：设计与可读性实操

## 证据与边界（设计前记住）

- 系统综述（[Do we feel colours?](https://doi.org/10.3758/s13423-024-02615-z)，132 篇研究、42,266 名参与者）：颜色与情绪是**多对多**关联，色相、明度、饱和度都起作用；仅收录英文文献可能有偏差。
- [跨国研究](https://pubmed.ncbi.nlm.nih.gov/32900287/)（30 国 4,598 人）：存在跨文化共性，也有随语言与地域变化的差异。
- 因此：关联 ≠ 因果 ≠ 对个人的预测。不把颜色当心理诊断，不假定用户想用配色改变情绪；用户偏好永远优先于下表。

## 心情族 → 起手方向

先明确用户要**表达当前心情**还是**营造不同氛围**，再从下表取起点。示例 hex 仅为起手值，不是处方：

| 心情描述 | 设计方向 | 起手示例（背景 / 前景 / 点缀） |
|---|---|---|
| 平静、放松、安稳 | 低饱和蓝绿青，过渡柔和 | `#1f2b2e` / `#d6e4e4` / 青 `#8fd0c9` |
| 喜悦、兴奋、有活力 | 背景保持中性，暖色（杏、珊瑚、柔黄）作点缀 | `#2b2622` / `#ece2d4` / 珊瑚 `#f0a583` |
| 温暖、想被安慰 | 暖中性（奶茶、暖灰），整体柔和但对比达标 | `#2d2a26` / `#e6ddd2` / 暖黄 `#e8c97a` |
| 专注、沉稳 | 深蓝灰底，克制的中明度冷色点缀 | `#1e2430` / `#d5dce8` / 钢蓝 `#7ca6c8` |
| 疲惫、紧张、低落 | 想换氛围：柔和蓝绿、雾紫降低刺激；想表达：按其描述设计，不假定需要安抚 | `#262a33` / `#d8dbe4` / 雾紫 `#a99cc4` |
| 混合情绪 | 中性背景 + 两三个低饱和点缀分别呼应 | 按组合取 |

文献中的大致趋势（供理解，不是映射规则）：红系唤醒度较高、可正可负；黄橙常与愉悦相关；蓝绿常与放松相关；亮色更常报正向、暗色更常报负向——这是群体统计，不等于"暗色主题 = 心情差"。

## 对比度核算（手算方法）

以 [WCAG 2.2 AA 普通文本 4.5:1](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 为设计目标（借用，非终端整体的无障碍认证）：

1. 每通道 c/255 得 c′（0–1）；
2. 线性化：c′ ≤ 0.03928 时 `c′/12.92`，否则 `((c′+0.055)/1.055)^2.4`；
3. 相对亮度 L = 0.2126R + 0.7152G + 0.0722B（R/G/B 用线性化后的值）；
4. 对比度 = (L亮 + 0.05) / (L暗 + 0.05)。

算例：前景 `#d8dee9`、背景 `#202838` → L ≈ 0.727 与 0.021 → 对比度 ≈ 10.9:1，达标。

必查对（除 color0/8 外全部 ≥4.5:1）：

- foreground / background
- selection_foreground / selection_background
- 光标文字 / 光标（如 cursor_text_color / cursor）
- color1–color7、color9–color15 对 background（color7、color15 常被程序当默认前景，重点查）

color0（黑）与 color8（亮黑/注释）常被有意压暗，允许低于 4.5:1，但与背景仍须可辨认。透明背景、背景图、显示器与色觉差异都会改变实际观感——计算按不透明 sRGB 进行，且要在交付报告中说明。

## 16 色语义检查表

| 索引 | 惯例语义 | 设计规则 |
|---|---|---|
| 0 | 黑 | 贴近背景的深色即可，但仍与背景可辨 |
| 1 / 9 | 红：错误、删除 | 对背景 ≥4.5:1；9 为明亮版 |
| 2 / 10 | 绿：成功、新增 | 同上 |
| 3 / 11 | 黄：警告 | 同上 |
| 4 / 12 | 蓝：目录、链接 | 同上 |
| 5 / 13 | 品红：关键字等 | 同上 |
| 6 / 14 | 青 | 同上 |
| 7 | 白：许多程序的默认前景 | 必查，通常接近 foreground |
| 8 | 亮黑：注释、次要文本 | 可低于 4.5:1 但须可辨 |
| 15 | 亮白：亮色环境默认前景 | 必查 |

程序可能反转前景背景、输出真彩色或加粗——计算之外仍需实际终端预览；不要仅靠颜色传达状态（红/绿信息同时配符号）。

## Do / Don't

Do：深色与浅色背景分别设计、分别核算对比度；高饱和色只作小面积点缀；一次给用户 1–2 个可选方向。
Don't：荧光高饱和铺满背景；把情绪与颜色一一对应（红=愤怒、暗=负面）；浅色主题直接反转深色调色板；为凑对比度修改透明度等非颜色设置。
